# CHG-007：真机接入与限流调优（glm-4.7-flash 实测记录）

- 日期：2026-08-29
- 动机：接入真实 LLM（智谱 glm-4.7-flash）执行 M2/M5 真机验收。
- 类型：修改（配置/提示词调优）+ 验收记录

## 变更内容

| 项 | 变更 | 依据 |
|---|---|---|
| `config.py` retry_delays | (1,2,4) → (2,4,8,16)，单次调用最多容忍 ~30s 拥堵 | 智谱 429（code 1305"访问量过大"）高峰实测：15s 重试链不够 |
| `models/task.py` turn_timeout_s | 120 → 180 → **300** | 每轮 7~9 次 LLM 调用，高峰期重试等待挤占墙钟；300s 下 ④号防护仍正确触发 |
| `executor/prompts.py` | system prompt 注入 **12 表紧凑目录**（名称+用途，~200 token） | 实测模型存在重复 search_schema；目录让其首轮锁表，省 1~3 个探索步 |
| `.env` | 供应商切换智谱：`glm-4.7-flash` + `embedding-3`（同 key） | 用户指定 |

## 真机验收证据（已完成部分）

1. **真实 GLM 正确驱动工具循环**：多次运行观察到 search_schema → get_schema×3 真实执行，引擎/工具/回填全链路正常。
2. **口径库注入生效**：模型回答中复述"成交额 = trades.amount 求和，营业部维度通过 branch_id 关联"——正是 memory.db 里沉淀的口径。
3. **SQL 质量合格**：模型产出的三表 JOIN + 近一月过滤 + 分组排序与金标同构（`date('now','-1 month')` 写法被 system prompt 以外的模型自身选择，评测比对不受影响）。
4. **四层防护在真实条件下正确工作**：两次墙钟触发均走 `wall_clock_summary`，模型诚实总结"已完成 SQL 编写、未完成执行"而非幻觉编造数据——**诚实失败优于幻觉**（PRD 核心叙事）得到真机验证。
5. **pytest -m eval 真实冒烟通过**：3 个真实案例全链路（分类→引擎→工具→评测判定）跑通，报告结构完整。

## 未竟事项（外部依赖阻塞）

- "单轮取数返回真实查询结果"的完整验收被**智谱服务端拥堵**阻塞（HTTP 429 code 1305，免费 flash 模型晚高峰实测连续 5 连 429）。工程侧无未修复缺陷。
- 恢复命令（错峰执行即可）：
  ```
  PYTHONPATH=src python -m t2s.ui.repl -q "客户总数是多少"
  PYTHONPATH=src python -m eval.runner            # 全量 50 → 准确率基线
  PYTHONPATH=src python -m eval.runner --no-memory --tag ablation   # 消融组
  ```
- 备选：`.env` 切换付费模型（如 glm-4.6）可立即验收，成本换取高峰可用性。

## 遗留调优点（二期）

- 429 专用退避（code 1305 可识别，单独放宽到分钟级 + 指数抖动）。
- 限流窗口内的请求合并/缓存（同 turn 内重复 system prompt 的供应商侧缓存协商）。

## 验收结果（2026-08-29 付费档 glm-4.7）

1. **单轮取数完整验收通过**：39.4s / 9 步 / 13,710 tokens，真实执行三表 JOIN 并返回结果；模型自主写出比常规 `-1 month` 更精确的自然月双端边界（`>= date('now','-1 month','start of month') AND < date('now','start of month')`），结论含 30 个营业部、最高 25.12 亿 / 最低 20.62 亿。
2. **评测冒烟 8/8 全对（单表档 100%）**：语法有效率 100%，平均步数 7.0，平均 token 7,435/题；报告 `eval/reports/report-full-20260829-163533.json`。样本小（N=8），JOIN/聚合/时间/歧义档待全量跑。
3. 过程修复：评测样例回收误调 `forget_pair`（MemoryService 方法）应为 `MemoryStore.remove_pair`。

**模型策略结论**：`glm-4.7-flash` 免费档晚高峰不可用（1305 拥堵），开发调试可用；评测与演示切 `glm-4.7` 付费档（高峰实测顺畅，单题成本约 7.4k token）。当前 `.env` 保持 glm-4.7。
