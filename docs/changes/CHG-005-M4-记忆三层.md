## 变更内容

| 文件 | 说明 |
|---|---|
| `src/t2s/llm/embeddings.py` | OpenAI 兼容 /embeddings 客户端：index 排序还原、数量校验、失败抛 EmbeddingError（上层降级）；MockTransport 可测 |
| `src/t2s/storage/memory_store.py` | qa_pairs / metrics_docs 两表存储；**按 question/title 幂等 upsert**（重复采纳更新而非堆叠）；向量 JSON 存储（ADR-007） |

| `src/t2s/utils/text.py` | 检索分词 + bigram 计分下沉复用（tools 与 manager 共用，二次出现即抽取——ADR-005 封装规则首次兑现） |

| `src/t2s/router/service.py` | 取数主路径接记忆：**检索（引擎前）→ 双通过自动沉淀（引擎后：stop_reason=final 且有 SQL）** |
| `src/t2s/config.py` | EmbeddingConfig（T2S_EMBEDDING_*，未配置 model 即禁用语义通道） |
| `scripts/seed_memory.py` | 口径库种子（月活跃/收益率/成交额三条口径）+ 2 条演示问答，幂等可重跑 |

**记忆闭环**（面试叙事）：
```
取数成功（双通过）→ record_success 向量化入库
        ↓ 下次相似问题
build_memory_context → 余弦 top-3 问答 + top-2 口径 → engine system prompt
        ↓
准确率提升 → M5 消融实验量化 Δ%
```

**降级链三层**：Embedding 未配置 → 关键词 bigram；API 失败 → 关键词；全零分 → 空块不注入。语义通道永远不阻塞主流程。

## 选型变更

Chroma → 自建 SQLite 向量存储，理由与备选见 **ADR-007**（重依赖 + 嵌入模型境外下载受网络阻断 + 本项目 <1k 向量量级 + 接口可插拔）。

## 过程中修复的缺陷

1. 测试断言设计：top_k=3 而库中仅 2 条样例时两条都返回——排序断言应比"排除断言"更符合检索语义；`row_count` 是结果集行数（COUNT 查询返回 1 行）不是聚合值。
