## 关键设计

1. **权重数字即设计立场**：关键词 0.7/语义 0.3 的不对称来自"失败模式不对称"——语义漂移产生语法正确但口径错误的 SQL，比漏召回危害大（ADR-008 D3）。
2. **复用统计是 rerank 与"表格字段复用"的合一实现**：用户行为（查了什么表）反哺检索排序，无需人工维护。
3. **白名单语义**：allowed_tables=None（全员只读，现状不变）→ 有值时才启用比对——存量用户零影响，受限用户渐进启用。
