## 语义变化（v2 确认制）

双通过自动沉淀 → **候选池**（检索不可见）；用户在 Web 确认/拖入 → **正式库**（few-shot 检索可见）。已确认状态不被重跑记录降级。种子数据直接 confirmed。

## 过程中修复的缺陷（diagnose 实录）

**QAPair.status 被模型默认值遮蔽**：all_pairs 重构后构造 QAPair 漏传 status，模型默认 'candidate' 掩盖了数据库中已确认的真值（confirm 后检索仍为空）。隔离测试（raw SQL 生效 vs ORM 读取不一致）定位到 ORM 构造层。教训：**数据模型新增字段时，所有构造点必须同步**；M7 编辑遗留的死代码 lambda（算了列号没用）是本次的案发现场。
